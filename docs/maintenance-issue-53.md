# #53: 프리셋별 프롬프트 주입 격리

1.6.40 에서 `excludePresets` 를 추가했다. 기본값은 `[]` 이며 옛 설정 동작을 바꾸지 않는다.

## 설정

현재 profile 의 `cordis.patch.yml` 을 백업하고, 이미 있는 `id: dsh-purge`(`name: dsh-purge-community`) 항목의 `config` 에 병합한다:

```yaml
excludePresets: [roleplay, minimal]
```

중복 플러그인 항목을 새로 만들지 않고 다른 필드를 덮어쓰지 않는다. 프리셋 ID 를 쓰고 대소문자와 앞뒤 공백을 무시하며 정확히 일치시킨다(`roleplay-extra` 는 `roleplay` 와 일치하지 않는다). `[]` 로 되돌리면 옛 주입 동작이 복원된다.

런타임은 현재 마운트된 프리셋을 먼저 읽고, 다음으로 최신 선택 이벤트, 프로젝션, 세션 헤더를 읽는다. 하위 Agent 는 자기 유효 프리셋을 쓰고, 공유 "최근 프리셋" 변수로 다른 세션 상태를 상속하지 않는다. 제외 목록이 설정되었는데 호스트가 해석 가능한 프리셋을 주지 않으면 주입을 멈추고 `assemble.excluded unknown=true` 를 기록한다. 무조건 주입하지 말고 호스트 컨텍스트/재로드를 점검해야 한다.

## 적용 범위

- 주 프롬프트, head/tail/both, 능력 프로토콜, boost, probe, postPrompt;
- assembly 재작성과 호스트 폴백. 선택 사항인 refusalRetry 는 요청 sessionId 로 실제 Agent 를 조회하며, 세션을 식별할 수 없으면 프롬프트를 덧붙이지 않는다;
- Purge 네임스페이스가 있는 단락 정리. 이 버전이 만든 재작성은 메모리 출처 기록을 붙여, 자신이 재작성/삭제/추가한 원래 단락을 복원한다;
- 사용자 텍스트를 바꾸지 않고, 이전 순수 텍스트에서 내용이 삭제되었다고 추측하지 않는다. 출처 기록은 영속화하지 않고 모델에 보내지 않는다. 옛 버전에서 남아 출처 정보를 잃은 순수 텍스트는 다시 조립해야 하며, 이전 대화에서 지워졌다고 약속할 수 없다.

제외된 세션은 assembly 서비스가 제공하는 페르소나, 워크스페이스 규칙, 도구, 변수를 유지하고, 더 이상 Purge 가 프롬프트 신원 재작성을 수행하지 않는다. 이미 설치된 전역 호스트 패치, 배포 설정(예: `includeHarnessIdentity`), 네트워크/권한 설정, 과거 대화는 그대로 유지된다. 이 옵션은 세션별 권한 패치 철회가 아니고, 플러그인 명령·패널·도구를 끄지도 않는다.

## 업그레이드와 롤백

설치 패키지는 플러그인만 갱신한다. 옛 호스트 #87 의 무인자 폴백 호출은 사용자가 고른 시점에 새 패치를 적용하고 직접 완전 종료 후 재실행해야 한다. 이 수정은 기존 호출을 현재 Agent 를 넘기는 형태로 마이그레이션하며, 반복 적용해도 중복 삽입하지 않는다. 마이그레이션 전에는 비어 있지 않은 제외 목록에서 무인자 폴백이 빈 값을 반환하고, 정상적으로 컨텍스트가 있는 section/assembly 는 여전히 프리셋대로 처리된다.

수정 전에 profile 을 백업하고, 설정을 되돌리면 `excludePresets: []` 로 복원된다. 코드를 되돌려야 하면 기존 백업/롤백 명령을 쓰고 그다음 수동 재로드를 잡는다. 새 호스트가 넘기는 추가 인자는 옛 JS 함수가 무시하며, 롤백은 프롬프트 원문, 프리셋 라이브러리, 프록시를 바꾸지 않는다. 사용자가 쓰고 있는 DSH 를 자동 재시작하지 않는다.

## 테스트

`test/preset-injection.test.mjs` 는 기본 호환, 현재 프리셋 해석, 모든 주입 단락, 잔여 정리, 하위 내용 보존, 100로 인터리브된 세션, 하위 Agent, 그리고 옛 무인자 호출의 LF/CRLF 마이그레이션과 멱등 실행을 커버한다.

`scripts/check-preset-runtime.mjs` 는 명시적으로 지정한 실제 호스트에 읽기 전용 인수를 수행하며, 임시 profile 에서 그 Cordis, SystemPrompt, 마이그레이션된 step 요청 구성 코드를 호출한다: standard/minimal/roleplay 전환, 60로 병렬과 하위 Agent, complete 프리셋. 요청 구성은 모델 호출 직전에 끝나므로 실제 과금 모델, 계정, 사용자 대화를 건드리지 않는다. 이 스크립트도 세 플랫폼 공식 npm 호스트 설치/롤백 CI 에 들어간다.

```sh
PURGE_TEST_HOST=/path/to/isolated/node_modules/@deepseek-ai node scripts/check-preset-runtime.mjs
```

제외된 세션은 Purge 프로브를 반환하지 않으므로 그것으로 플러그인 고장을 판정할 수 없다. 전역 주입 경로를 점검할 때는 제외되지 않은 프리셋을 쓴다.

이것은 결정적인 주입 경계와 실제 호스트 서비스를 검증하는 것이며, 실제 모델 응답 품질 테스트라고 표현하지 않는다.
