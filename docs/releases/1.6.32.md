# Purge Community 1.6.32

#40 에서 다룬 데스크톱 아카이브 진단 대상 불일치를 수정한다.

- 상단 상태, 계층별 자체 점검, 앵커 진단이 같은 설치의 실제 디스크 디렉터리를 일관되게 검사한다.
- Electron 이 app.asar 에서 기동할 때 아카이브 내부 경로를 실제 파일 검사기로 잘못 넘기지 않는다.
- 실제 파일 누락, 읽기 이상, 아카이브 레이아웃, 권한 차이 경고는 유지한다; "디스크에 기록됨"을 "실행 중 로드됨"으로 보지 않는다.
- 패치 기능, 프롬프트, 사용자 설정, 설치/재시작 정책은 바꾸지 않는다.
- macOS/Windows 실제 Electron 아카이브와 HTTP 인터페이스 회귀를 추가하고, 세 플랫폼 설치 및 패키징 검사를 계속 실행한다.

이번에 확인한 것은 재현 가능한 경로 진단 결함이다. 보고자의 구체적인 DSH 버전과 남은 빨강 항목은 그 진단 정보로 확인해야 한다.
자세한 내용은 [유지보수 안내](../maintenance-issue-40.md) 를 본다.
