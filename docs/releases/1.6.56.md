# 1.6.56

- **상태 페이지 성능(PR #82)**: 같은 읽기 전용 진단 안에서 호스트 신원, 설치 루트, 경로 해석을 공유해 중복 디스크 호출을 줄인다. 캐시는 조회 사이에 유지되지 않으므로 패키지 교체, 파일 삭제, 링크 변경 이후에도 옛 증거를 쓰지 않는다.
- **상태 오류(#83)**: 동시에 시작된 같은 상태 요청을 병합한다; 타임아웃, 비 JSON, 인터페이스 오류는 원인을 유지하고 "상태 알 수 없음"을 표시하며, 더 이상 `0/0` 또는 "호스트 미확인"으로 잘못 보고하지 않는다. 새로고침으로 재시도할 수 있고, 실제 누락과 패치 드리프트는 계속 표시된다.
- **테마 대비(PR #81)**: 드릴 콘솔 검색 버튼과 보고서 단계 번호가 짝을 이룬 테마 색을 쓰도록 하고, 커뮤니티 버전과 독립 패널 빌드를 함께 갱신한다.
- 기존 패치 정의, 프롬프트, 프리셋, 설정, 권한은 유지한다; 패치를 자동 적용하거나 DSH 를 재시작하지 않는다.

## 검증과 경계

전체 회귀, 네이티브 Electron 상태 인터페이스, Mac/Windows 격리 설치, 마이그레이션, 롤백, 실패 복구 검수 기록은 [유지보수 안내](../maintenance-issues-81-83.md) 를 본다. #83 의 스크린샷 오보는 재현했다; 옛 버전 Windows 상태 조회 지연도 재현했지만, 보고자의 60초 전체 타임아웃은 그 시스템/DSH 버전과 업데이트 후 결과로 확인해야 하므로 issue 는 열린 상태로 둔다.
