# 1.6.48

사용자 정의 프롬프트 보호와 별칭 설치의 유지보수 흐름을 수정한다.

- **#72**: 본문에 템플릿 키워드가 있다는 것만으로 기본 내용이라고 판단하지 않는다. 명시적 사용자 정의, 수동 편집, 출처가 불분명한 본문은 보존한다; 기동 동기화, 적용, 설치가 같은 판정을 공유한다. 읽기 실패 시 파일을 덮어쓰지 않는다. 확인된 기본값 업그레이드와 명시적 기본값 복원은 유지한다.
- **#74**: 버전 대조가 표준 설치 이름과 `dsh-purge` 별칭을 인식하고 실제 패키지 신원을 검증한다; YAML 의존성은 실제 패키지 위치에서 읽는다. 별칭 설치의 백업, 업그레이드, 롤백을 수정하며, 롤백은 원래 의존성 이름, 진입점, 이후 사용자 설정을 보존한다.
- 누락, 손상, 여러 사본의 모호함을 숨기지 않고, 업데이트 오류를 지워 고쳐진 것처럼 만들지 않는다. 호스트 패치, 주입 내용, 권한, 프록시, 업데이트 선호를 바꾸지 않으며 자동 재시작도 없다.

옛 버전의 대조 오류가 자동 설치를 막을 수 있으므로 새 버전 독립 설치기로 제자리 업그레이드한다; 제거 후 재설치할 필요는 없다. 옛 버전이 덮어쓴 개인 본문은 사용자 원고나 백업에서 복구해야 하며, 이 버전이 자동으로 재구성할 수 없다. 옛 버전으로 롤백하면 그 옛 결함도 함께 되살아난다.

검증과 적용 경계는 [유지보수 안내](../maintenance-issues-72-74.md) 를 본다.
