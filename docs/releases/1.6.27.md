# 1.6.27 — 끼어들기 회귀 수정

이 버전은 메시지 전달 마이그레이션 #90 만 수정하고, 네이티브 가드를 복원하며, 옛 #85/#86 마이그레이션을 보강한다. 나머지 패치 정의 79개는 1.6.26 과 항목별 직렬화 비교에서 일치한다; 사용자 프롬프트, 프리셋, 설정, 답변 대기 규칙은 다시 쓰지 않는다.

로컬 검수:

- `npm test`: 174 항목, 169 통과, 특정 플랫폼 테스트 5 항목 건너뜀, 0 실패.
- 실제 설치된 DSH 0.2.1-rc.2 메서드 대상: 런타임 테스트 18 항목 통과.
- 새로 추가/확장한 끼어들기 마이그레이션, 런타임, 파일 테스트 합계 34 항목이며 옛 고장의 음성 대조를 포함한다.
- UI 계약 검사 통과, 패널 11 항목 테스트 통과; 빌드 일관성, 포맷, 문서 버전 검사 통과.
- tgz 무의존 부트스트랩, export/모듈 임포트, 프리셋 해석, CLI, 자체 점검 smoke 통과.

실제 메서드 테스트는 메모리 영속화와 클라이언트 프로젝션을 쓰고 모델을 호출하지 않으며, 자동 재시작이나 사용자 DSH 조작도 하지 않는다. 크로스 플랫폼 CI 기록은 GitHub Actions 에 있다; Linux/Windows 러너 통과를 사용자 PC 의 전체 GUI 검수로 쓰지 않는다.

업그레이드 후 설치, 적용, 재로드는 따로 진행한다. 알 수 없는 개정은 해당 파일 마이그레이션을 중단하고 보고한다. #25 는 보고자가 버전, 조작 경로, 실제 결과를 확인할 때까지 열린 상태로 둔다.
