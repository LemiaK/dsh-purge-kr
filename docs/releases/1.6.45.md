# 1.6.45

#64 의 "적용 미완료"가 `CMD 무감지 미고정(unknown)` 으로 오보되던 진단 문제를 수정한다(PR #66).

- 백엔드가 기존 완료 판정에 쓰는 호스트 쓰기, 설정 복구 결과를 반환한다; 패널은 패치 실패, 호스트 미기록, 설정 복구 실패, CLI 런타임 실패, 명확한 터미널 검사 실패를 각각 표시한다.
- 옛 백엔드가 구체적 원인을 반환하지 않으면 원인 미상임을 명확히 알리고 오류 상태를 유지한다; CMD 실패를 근거 없이 단정하지 않고 프롬프트가 기록되었다고 근거 없이 주장하지 않는다.
- 회귀 테스트 6건을 추가해 옛 응답, 여러 가지 실제 실패, 번역, 실제 React 컴포넌트의 Apply 상호작용(HTTP 경계 시뮬레이션)을 커버한다. 시뮬레이션 테스트로 보고자 환경 검증을 대신하지 않는다.

이 버전은 진단과 표시만 고치며 완료 조건, 호스트 패치, 프롬프트, 권한 설정, 재시작 동작을 바꾸지 않는다. 릴리스 작업은 메인테이너의 로컬 설치와 설정을 바꾸지 않고 DSH 를 재시작하지 않는다.

#64 의 원래 호스트 적용 실패는 여전히 보고자의 클라이언트 릴리스 이름, 클라이언트 및 기저 DSH 버전, 운영체제, 업데이트 후 민감정보를 제거한 오류 정보가 필요하다; issue 는 열어 둔다. #63 의 서드파티 클라이언트 지원은 아직 조사 중이며 이 버전은 호환을 주장하지 않는다. 프롬프트, 자격 증명, 전체 설정을 업로드하지 않는다.

자세한 내용은 [진단 및 호환성 기록](../maintenance-issues-63-64.md) 을 본다.
