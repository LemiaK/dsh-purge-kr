# 1.6.8 Windows 실기 설치 검수

환경: 실제 Windows 11 Pro, build 26300; 공식 DSH Desktop 0.2.1-rc.2 Windows x64. 설치 패키지와 앱 exe 의 Authenticode 서명이 유효하며 발급 주체는 DeepSeek 이다. 독립 테스트 앱 디렉터리, DSH_HOME, user-data-dir 를 사용했고 사용자 계정, 자격 증명, 기존 업무 데이터는 포함하지 않는다.

## 실기에서 발견한 문제

1.6.7 의 PowerShell 진입점이 call operator 로 Desktop exe 를 실행했다. 이 exe 는 GUI 서브시스템 프로세스라 PowerShell 이 먼저 반환한 뒤 finally 에서 임시 스크립트를 삭제할 수 있었다. 실측에서 부모 프로세스는 성공으로 반환했고 자식 프로세스는 나중에 MODULE_NOT_FOUND 를 보고했다. 이전 GitHub Windows 러너의 일반 Node 콘솔 대체물로는 이 차이를 커버할 수 없었다.

## 수정과 회귀

- Start-Process 로 해당 프로세스 완료를 기다리고 실제 ExitCode 와 UTF-8 stdout/stderr 를 읽은 뒤 임시 디렉터리를 정리한다.
- Windows 원시 인자는 완전한 인용 부호 규칙으로 전달한다; shell 문자열 결합으로 명령을 실행하지 않는다.
- 지연 읽기 스크립트를 위한 실제 GUI 서브시스템 테스트 프로그램을 추가했다. 성공, 인자 전달, 비정상 종료를 커버하며 Windows PowerShell 5.1 / PowerShell 7 에서 실행한다. 이 프로그램은 회귀 대체물일 뿐 실제 DSH 설치 검수는 따로 기록한다.

## 검증된 범위

- 공식 Desktop 사본을 실제로 기동해 그것이 독립 desktop profile 을 생성하는지 확인했다; 여기서는 초기화 단계만 검증했고 전체 UI 검수라고 주장하지 않는다. 일반 CLI 는 예약된 desktop profile 을 만들 권한이 없으므로 손으로 쓴 설정으로 이 단계를 대신할 수 없다.
- 수정된 PowerShell 진입점에서 실제 Desktop Electron 과 내장 CLI 로 공개 릴리스 패키지 SHA256 검증, 설치, 스냅샷, 롤백을 완료했다.
- 기존 테스트 프롬프트는 유지되었고, 백업 후 프롬프트를 수정했으며 플러그인 롤백 후에도 이후 내용이 유지되었다.
- 테스트는 호스트 패치를 자동 적용하지 않고 사용자가 이미 쓰는 DSH 를 재시작하지 않으며 기존 이미지 생성 서비스와 네트워크 프록시를 바꾸지 않는다.

이번 설치 검수에서 전체 Windows UI, 계정 로그인, 전체 호스트 패치 기능의 통과를 주장하지 않는다. 이 기록에는 호스트 주소, 실제 사용자 이름, 계정 파일, 사설 경로가 없다.

보충: 같은 Windows 11 실기에서 원시 CLI 로 마켓 Git 소스 방식 설치도 통과했다(공급망 검증 유지, 프로세스 단위로 공개 미러 선택). 해당 설치를 1.6.8 후보 패키지로 업그레이드했고 현재 프롬프트는 변하지 않았다. 이 PC 에서는 issue #7 제출자 당시의 메타데이터 누락 오류를 재현하지 못했으며, 한 번의 성공을 모든 네트워크/미러 환경을 커버한 것으로 등치하지 않는다.

[세 플랫폼 및 GUI 프로세스 회귀 CI](https://github.com/kingcharleslzy-ai/dsh-purge/actions/runs/39097652231) 가 모두 통과했다. 실제 기기 검수와 CI 대체물의 결과는 따로 기록한다.

정식 릴리스 후 재확인: 위 Windows 11 에서 공개 v1.6.8 PowerShell 진입점으로 SHA256 검증과 실제 Desktop 설치를 완료했고 PowerShell 7 도 dry-run 을 완료했다. 공개 패키지로 스냅샷과 롤백도 다시 수행했고 현재 프롬프트는 유지되었으며 기본 DSH_HOME 은 여전히 생성되지 않았고 기존 이미지 생성 서비스는 계속 동작한다. [릴리스 CI](https://github.com/kingcharleslzy-ai/dsh-purge/actions/runs/39097728324) 와 마켓 릴리스가 통과했다.
