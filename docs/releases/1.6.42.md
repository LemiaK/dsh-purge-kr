# 1.6.42

PR 검토 중 재현된 내용 보존, 스트림 취소, 설정 로그 문제를 고친다.

- 프롬프트 분할은 코드 펜스 밖에서 한 줄 전체를 차지하는 옛 대문자 표식만 인식한다; 본문, 인용, 들여쓴 코드, 코드 펜스 안의 같은 문자열은 보존한다. 인식을 새 대소문자 형태로 확장하지 않는다.
- 사용자가 정상 답변을 취소하면 상위로 종료 작업을 전파해 연결이 계속 점유되지 않게 한다; 같은 반복자는 한 번만 닫는다.
- 스트림 진단은 소스가 끝난 뒤에 text, tool_call, reasoning_only 또는 empty 를 기록한다; 늦게 도착한 오류와 사용자 취소는 따로 기록한다. 이는 전송 결과를 뜻하며 답변이 옳거나 작업이 성공했다는 뜻이 아니다; 새 진단은 응답 본문이나 오류 원문을 저장하지 않는다.
- 설정 변경은 쓰기 진입점에서 실제 변화만 기록하고 변화가 없으면 중복 기재하지 않는다; 미지 설정은 보존하되 감사에 넣지 않는다. 저장 실패를 성공으로 기록하지 않으며 무효 필드 값을 원문 그대로 로그에 쓰지 않는다.
- retry 스위치의 적용 설명을 정정한다: 다음 요청에서 읽는다; rewind 의 UI 재로드 요구는 유지하며 즉시 적용된다고 오보하지 않는다.

loLollipop 이 PR #59, #60, #61 에서 제공한 단서에 감사한다. 이 버전은 독립적인 신뢰성 수정이며 #58–#61 을 일괄 병합하지 않았다; 해당 원 PR 은 열린 상태로 남기고 채택하지 않은 부분은 이후 논의를 위해 유지한다. 기존 감지 규칙, 재시도 문구, 기본값, 호스트 패치는 변하지 않는다.

사용자 설정, 프롬프트 파일, 설치를 수정하지 않고 패치를 자동 적용하거나 DSH 를 재시작하지 않는다. 테스트 범위와 채택하지 않은 항목은 [유지보수 안내](../maintenance-pr-58-61.md) 를 본다.
