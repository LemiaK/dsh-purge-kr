# Purge Community 1.6.36

## #40 수정 유지

이 버전은 1.6.35 에서 도입한 macOS 수동 종료 후 패키지 교체와 진단 일관성 수정을 그대로 유지한다:

- 독립 도우미가 대상 앱과 하위 프로세스의 완전한 종료를 기다리고, 원본 아카이브를 검증·백업한 뒤 패키지를 교체한다; DSH 를 자동 종료하거나 다시 열지 않는다.
- 패널과 CLI 가 미예약, 대기, 완료, 실패, 미지 상태를 구분한다; 디스크에 기록되었다는 것이 실행 프로세스에 로드되었다는 뜻은 아니다.
- 진단이 같은 설치 디렉터리를 쓴다; 설치되지 않은 서드파티 프리셋을 오보하지 않고, 설치된 리소스의 누락·손상·읽기 불가는 계속 알린다.

구체 동작, 검증 경계, 사용 절차는 [1.6.35 릴리스 노트](1.6.35.md), 장애 점검과 복구는 [#40 유지보수 안내](../maintenance-issue-40.md) 를 본다. 1.6.36 의 다른 변경 기록은 [버전 이력](../../release-notes.md#1636) 을 본다.

## 공개 버전 검증

정식 릴리스 commit 은 `fa295be1808a010ff7bfc100322446dcc588d630` 이다. 1.6.35 와 비교해 #40 관련 구현, 회귀 테스트, 세 플랫폼 workflow 가 동일하게 유지되었다.

- [세 플랫폼 검사](https://github.com/kingcharleslzy-ai/dsh-purge/actions/runs/39540631028) 통과.
- [릴리스 검사](https://github.com/kingcharleslzy-ai/dsh-purge/actions/runs/39540640543) 통과: macOS 실제 Electron 수동 종료 패키지 교체, 재기동과 롤백, Windows Electron 패키지 교체 검수 포함.
- [정식 다운로드 페이지](https://github.com/kingcharleslzy-ai/dsh-purge/releases/tag/v1.6.36)의 버전 패키지와 범용 이름 패키지가 모두 릴리스 매니페스트 SHA256 검증을 통과했고, 패키지 안의 #40 수정 파일도 대조와 일치했다.

이 결과는 보고자가 자기 macOS 15.7.4 / DSH nightly 환경에서 재측정하는 것을 대신하지 않는다. 실제 고장과 런타임 미지는 여전히 유지보수 안내에 따라 점검한다.

## 문서와 버전 메타데이터 보완

릴리스 후 이 페이지를 보충하고 중국어/영어 README 의 릴리스 노트 링크를 고쳤으며, 루트 `package-lock.json` 의 프로젝트 버전 두 곳을 `1.6.36` 으로 동기화했다. 의존성 버전과 무결성 기록은 변하지 않는다; 이번 보완은 런타임 코드, 사용자 설정, 이미 배포된 설치 패키지를 수정하지 않으며 기존 버전 tag 도 이동하지 않는다.
