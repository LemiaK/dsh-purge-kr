# 1.6.31

## #38 수정: 기본 프리셋 자체 점검 오보

1.6.30 에서 집계를 조이면서 기본 프리셋에 실행할 필요가 없는 #76 의 skipped 상태를 고장으로 셌다. 이 버전은 읽기 전용 진단만 조정하고 호스트 패치 표, 매칭 규칙, 사용자 프리셋, 프롬프트, 권한을 수정하지 않는다.

- #76 의 모호한 skipped 상태에 대해 현재 DSH_HOME 아래 프리셋 본문을 정적으로 파싱한다; persona.prefix 가 대상 문장을 포함하지 않는 리터럴 텍스트임을 확인하면 "처리 불필요"로 표시하고 적용됨이나 필수 실패 항목으로 세지 않는다.
- 모든 optional/skipped 를 일괄 제외하지 않는다. 대상 문장이 남아 있는데 앵커가 맞지 않으면 계속 오류로 보고한다; 적용 대기는 여전히 적용 대기로 표시한다; 필수 파일 누락은 계속 경고한다.
- YAML 손상, 필드 중복 또는 persona, 동적 표현식, 상속/별칭, 읽을 수 없는 파일, 판단할 수 없는 구조는 미지로 표시하고 표현식을 실행하지 않으며 다른 profile 을 스캔해 현재 파일을 대신하지 않는다.
- 사용자의 기존 설정과 모든 기능을 유지하고 호스트 패치를 자동 적용하거나 DSH 를 재시작하지 않는다.

## 검증

기본 프리셋의 LF/CRLF, 주석, 빈 접두사, 적용 대기, 표식 존재, 잔여 identity 문장, 비정상 YAML, 동적 표현식 미실행, 읽기 실패, 실제 대상 누락 조합 회귀를 추가했다. 테스트는 실제 #76 상태 감지를 호출한 뒤 자체 점검 집계를 거쳐 기본 경로와 오류 경로를 동시에 커버하는지 확인한다. 정식 릴리스는 여전히 Linux/macOS/Windows 테스트 게이트가 통제한다.

이 PC macOS: 테스트 212건, 207 통과, 5건 플랫폼 건너뜀; Windows 11 실기 격리 디렉터리: 테스트 212건, 209 통과, 3건 플랫폼 건너뜀, 실제 TLS/프록시와 Electron 인계 포함. 양쪽 실제 Electron 44.7.0 자체 점검 통과. 테스트 스크립트가 Windows 에서 테스트 하위 프로세스를 먼저 종료한 뒤 임시 ASAR 를 삭제하도록 처리했고, 호스트 패키지 교체 로직은 수정하지 않았다. Windows 릴리스 패키지 smoke 도 통과했으며, 테스트 스크립트가 npm.cmd 를 직접 실행하던 기동 방식을 고치고 패키징 검사를 세 플랫폼 PR 및 릴리스 CI 에 추가했다.
