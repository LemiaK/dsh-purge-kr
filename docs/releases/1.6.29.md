# 1.6.29

## 수정

- #34: 패널 롤백을 아카이브 설치로 바꿔 맨 디렉터리가 의존성이 빠진 `link:` 를 만드는 것을 피한다. 설치 후 새 프로세스에서 의존성과 플러그인 진입점을 검증한다; 실패하면 작업 전 의존성 그래프, 매니페스트, 잠금 파일을 복원한다. 기존 백업과 호환되고 현재 프롬프트와 설정을 보존한다.
- #35: 두 플러그인의 업데이트 요청을 통합하고 GitHub token, 환경 프록시, 읽기 전용 Windows 정적 시스템 프록시를 지원한다; 인증 정보는 GitHub API 로만 보내며 교차 출처에는 싣지 않는다. 할당량 소진, 인증, 리소스 불가, 연결 시간 초과를 구분하고 Atom 폴백과 옛 캐시 상태를 표시한다.
- Windows Node 22 의 링크 트리에서 재귀 cpSync 를 쓰면 프로세스가 네이티브로 종료되던 문제를 수정해, 의존성 체크포인트가 링크를 명시적으로 복사하고 보존한다.
- 기존 호스트 패치, 도구, 프롬프트 정책은 변하지 않는다; 시스템 프록시를 바꾸지 않고 패치를 자동 적용하거나 DSH 를 재시작하지 않는다. Linux 설치 진입점은 따로 다룬다.

## 검수

Windows 11 / RTX 4090 실기, 독립 DSH_HOME 과 web profile, DSH 0.2.1-rc.2 실제 CLI 로: 옛 롤백의 의존성 누락 재현, 손상된 링크 복구, 옛 스냅샷 롤백, 재업그레이드, 주입 설치 후 검증 실패와 원 설치 복구를 단계별로 검증하며 진입점 로드를 확인했다. 기존 설정과 프록시 설정 요약은 일치했다. 실제 Electron 44.7.0 에서 명령, 도구, 프롬프트, 인터페이스 등록과 해제가 통과했다; 사용자 DSH 는 재시작하지 않았다.

자동 테스트 199건: macOS 194 통과, 5건 플랫폼 건너뜀; Windows 195 통과, 4건 플랫폼 건너뜀. 실제 CONNECT/TLS 테스트가 프록시 인증, 교차 출처 token 격리, 인증서 검증, 시간 초과, 크기 제한을 커버한다; 4090 에서 릴리스 목록, 검증 파일, Atom 실제 요청이 통과했다.

설명: 1.6.28 의 디렉터리 롤백 수정에는 이 패널 진입점이 포함되지 않았고 #34 가 이 버전에서 보완한다. PAC/SOCKS 는 지원하지 않는다; 독립 bootstrap 다운로더는 플러그인 내부 통합 네트워크 계층이 아니다. 자세한 경계는 [유지보수 안내](../maintenance-issues-34-35.md) 를 본다.
