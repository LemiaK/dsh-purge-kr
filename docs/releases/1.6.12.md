# Purge Community 1.6.12 검수 기록

1.6.11 의 마지막 공개 Windows PowerShell 진입점 실측이 실패했다: 언팩 패키지에서 migrate 를 실행할 때 의존성이 아직 설치되지 않았는데, bin/community.js 최상위에서 selfcheck 가 yaml 을 미리 로드했다. 이 실패는 마이그레이션 설치 기록 이전에 발생했다. 1.6.11 은 프리릴리스로 철회했다.

수정은 selfcheck 의존성을 해당 명령 분기로 옮긴 것이며, migrate/status 부트스트랩 단계에는 서드파티 의존성이 필요 없다. #12, #15 의 수정과 검증은 그대로 유지한다; [1.6.11 기록](1.6.11.md) 을 본다.

회귀를 추가해 실제 bin/lib/presets 를 node_modules 가 없는 임시 디렉터리로 복사하고, status 기동과 migrate 실패 경로가 의존성 누락 때문에 죽지 않는지 검증한다; 패키징 smoke 도 먼저 무의존 기동을 검증한 뒤 선언된 의존성을 설치해 플러그인 진입점을 테스트한다. 부트스트래퍼는 스스로 의존성을 설치하지 않고, 설치와 공급망 검증은 계속 현재 DSH CLI 가 관리한다.

4090 Windows 11 에서 실제 후보 tgz 로 전체 bootstrapInstall 을 수행했다: 언팩 디렉터리에 node_modules 가 없음을 확인한 뒤 공식 Desktop Electron/CLI 로 격리 profile 에 설치했고, 실제 설치 버전은 1.6.12 다; 프롬프트와 profile 설정 SHA256 은 바뀌지 않았고 자동 재시작도 없었다. 다운로드 단계는 후보 패키지 바이트와 SHA256 테스트 응답을 썼고, 실행 단계는 실제 언팩, 부트스트랩 CLI, 백업, 네이티브 설치이며 mock bin 이 아니다.

Mac Node 전체 117 항목: 112 통과, Windows 전용 5 항목 건너뜀; 4090 Windows 전체 117 항목: 115 통과, 플랫폼 조건에 따라 2 항목 건너뜀, 실패 없음. 패널 컴포넌트 10 항목, 실제 Electron ASAR, 무의존 릴리스 패키지 smoke 통과. 세 플랫폼 CI 와 공개 다운로드 후의 실제 설치는 릴리스 절차에서 계속 검사한다.
