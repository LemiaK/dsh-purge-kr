# 1.6.9 Windows 호스트 인계와 설정 호환 검수

이후 공개 패키지 재측정에서 언팩 후 다시 설치하면 Windows 상대 junction 이 잘못된 곳을 가리켜 실패할 수 있음을 발견했다. 1.6.9 는 프리릴리스로 전환했으므로 [1.6.10](1.6.10.md) 을 사용한다. 아래 내용은 당시 실제로 완료한 테스트를 보존한 것이며 전체 설치 체인이 통과했다는 뜻이 아니다.

환경: Windows 11 Pro build 26300, 서명이 유효한 공식 DSH Desktop 0.2.1-rc.2, Electron 44.7.0. 격리 앱 사본, 독립 profile, user-data-dir 를 사용했고 계정 자격 증명을 복사하지 않으며 기존 이미지 생성 서비스, 네트워크 프록시, 기본 DSH 데이터 디렉터리를 바꾸지 않는다.

## 수정

- #10 / PR #11: 디스크 패치를 적용한 뒤 핸드셰이크, 로그, 시간 초과, 아카이브 검증이 있는 대기 도우미를 쓴다. host 를 예약 종료하지 않고 앱을 죽이지 않으며 자동으로 다시 기동하지 않는다. 종료 후 고유한 원본 아카이브 백업을 남기고 SHA256 을 확인한 뒤 완료로 기록한다.
- 실기에서 Electron 의 Windows detached PowerShell 이 스크립트를 실행하지 않고도 0 으로 종료될 수 있음을 추가로 발견했다. 짧은 broker 로 독립 도우미를 기동하고 broker 와 도우미 기동 오류를 따로 기록한다. 회귀에서 Electron 이 기동한 프로세스가 끝난 뒤에도 도우미가 패키지 교체를 완료하는지 검증한다.
- #9: 최신 설정 서비스는 원시 describe/replace 를 유지하고 legacy register 를 노출하지 않는다. 업그레이드 시 알려진 옛 shim 만 제거하고 원시 설정 이벤트와 사용자 데이터를 보존한다; 알 수 없는 수정에서는 진단을 중단하고 옛 호스트는 호환 인터페이스를 유지한다.
- 백업 디스크립터가 닫히지 않아 Windows 파일 교체가 실패하던 문제를 수정했다; 백업 실패 시 쓰기를 중단한다. 설치 후 실제 코드 버전을 검증하고, 롤백 디렉터리 링크 문제로 재업그레이드가 옛 패키지를 로드하던 문제를 수정했다.
- 사용자 고지는 독립적으로 팝업 스타일을 가지며 사용자 자신의 확인을 유지한다. 디스크 패치와 현재 프로세스 로드 상태를 따로 표시한다.

## 실제 기기 결과

1. 정식 Desktop 런타임에서 설치, 백업, 1.6.8 로 롤백, 1.6.9 로 재업그레이드를 완료했다. 현재 프롬프트, 롤백 후 추가된 프롬프트 내용, profile 설정은 변하지 않았다.
2. 실제 호스트에 파일별 백업, 전체 패치 적용, 되돌리기, 재적용을 수행했고 실패 항목은 0 이었다; 되돌린 뒤 설정 모듈은 원본 바이트와 일치했다.
3. 실제 데스크톱 host 의 앱 인터페이스에서 새 도우미를 트리거해 waiting_for_quit, 데스크톱 세션 내 도우미 위치, host 응답 지속을 확인했다. 테스트 승인에 따라 격리 사본을 종료하자 도우미가 패키지 교체를 완료했고 아카이브 백업 SHA256 이 일치했으며 자동 재오픈은 없었다. 다시 열자 인터페이스가 sealed=false, handoff=complete, 플러그인 1.6.9 를 반환했다.
4. 재로드된 호스트 계층, 런타임 주입 등록 계층, 레이아웃 계층 자체 점검이 모두 ok 였다. 격리 profile 은 호스트 기본 권한을 따르므로 권한 선택 계층은 초록으로 표시되지 않았다; 설정을 그대로 유지하기 위해 자체 점검 때문에 권한을 고쳐 쓰지 않았다. 자체 점검 상태는 임의 모델 출력 검증과 같지 않다.
5. 실제 Settings, ConfigEditor, Loader 로 독립 테스트 profile 을 기동해 설정을 세 번 반복 읽고 저장한 뒤 다시 읽기에 성공했으며 legacy register 는 존재하지 않았다.
6. Windows PowerShell 5.1 전용 12건 통과; PowerShell 7 인계 전용 6건 통과. 실제 Electron 부모 프로세스 종료 후 인계 회귀도 있다. macOS 메인 테스트 100건 통과, Windows 조건부 4건 건너뜀, UI 컴포넌트 9건 및 실제 Electron ASAR 자체 점검 통과.

## 검증 경계

이 기록은 위 설치, 업데이트 복구, 호스트 패치 인계, 원시 설정과 상태 인터페이스를 커버한다. UU 데스크톱에서 앱은 표시되지만 자동 마우스 입력이 불안정하므로 모든 Windows 페이지 컨트롤을 사람이 클릭해 검수했다고 주장할 수 없다; 테스트 계정 로그인 흐름, 임의 모델의 거부율, 모든 서드파티 플러그인 조합은 테스트하지 않았다. 신구 설정 호환, 대기 도우미 예외 분기, 페이지 동작은 자동 회귀로 따로 커버한다.

기본 동작은 여전히 DSH 를 자동 재시작하지 않는다. 사용자가 명시적으로 승인한 테스트 재시작은 검수 작업이며 플러그인 기본 정책을 바꾸지 않는다. 호스트 주소, 실제 경로, 설정 본문, 계정 정보는 릴리스 패키지나 공개 증거에 들어가지 않는다.
