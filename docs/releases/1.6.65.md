# 1.6.65

- #18/#19(중복 호출 알림, 도구 결과 트리밍)를 `disabledByDefault` 로 바꿨다: 기본값은 호스트에 쓰지 않으며, `purge-community patches enable 18,19` 로 명시적으로 켠 뒤 "적용"을 한 번 눌러야 효력이 생긴다.
- `tuning.extraPatches`, `patchEnabled()`, `disabled` 상태를 추가했다; 자체 점검은 선택 항목의 비활성화를 명확한 해당 없음으로 계산하고 빨강으로 보고하지 않는다.
- 패널은 "선택 비활성"을 표시한다; CLI 는 list / enable / disable 을 지원하고 디스크 기록 시 `patches_setting` 을 남긴다.
- `npm test` 407 통과.
