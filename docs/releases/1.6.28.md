# 1.6.28

## 업데이트, 무결성 검증, 진단 롤백 유지보수

- #28 수정: profile 별로 실제 설치 버전을 검사한다; 부분 성공은 실패 대상과 오류를 보존하고 이후 실패 항목만 보충 설치하며 전역 버전 pin 이나 업데이트 완료 표식을 앞서 커밋하지 않는다.
- #29 수정: 옛 상위 ZIP 채널은 commit 을 먼저 고정한 뒤 파일마다 Git blob 다이제스트를 대조한다; 내용이 바뀌었거나, 빠졌거나, 파일이 더 있거나, 매니페스트를 검증할 수 없으면 중단하고 설치 디렉터리를 바꾸지 않는다. 정식 TGZ 의 SHA256SUMS 검증은 그대로 유지한다.
- loLollipop 의 PR #27 통합: 자체 점검이 상태를 읽지 못할 때 더 이상 전부 초록으로 표시하지 않고, rc.2/rc.10 정렬과 버전 스탬프 혼동을 수정하며, 짧은 파일 점유에 대해 제한된 재시도를 한다.
- 디렉터리 롤백 보강: node_modules, .git, 파일 실행 권한을 보존한다; 의존성을 되돌리지 못하면 롤백 전 디렉터리를 복원하고 명확히 오류를 낸다. 신규 설치 실패로 생긴 반쯤 설치된 디렉터리는 격리해 보존하고 기존 디렉터리를 임의로 삭제하지 않는다.
- 호스트 패치 80건 유지; #90 은 불필요한 optional 표기만 삭제하고 엄격 매칭과 교체 동작은 변하지 않는다. 프롬프트, 프리셋, 권한, 업데이트 선호는 변하지 않으며 호스트 패치를 자동 적용하거나 자동 재시작하지 않는다.

## 검증과 경계

- 이 PC 테스트 191건: 186 통과, 5건 플랫폼 전용 건너뜀; UI, Electron 자체 점검, 문서 일관성, 실제 패키징 smoke 통과.
- 크로스 플랫폼 CI 가 Linux, macOS, Windows 및 Windows PowerShell 5.1/7 설치 진입점과 격리 Electron 생애주기를 커버한다. 이 결과는 사용자 4090 데스크톱의 새로운 GUI 검수가 아니다.
- 실제 상위 commit ec69166706bed95efb6c35e225b01588f3cd9b72 의 파일 118개가 Git tree 검증을 통과했다; GitHub 가 가리키는 commit 과 일치한다는 검증이며 배포자 서명이나 상위 코드 안전성 보증이 아니다. API 를 쓸 수 없을 때 검증 건너뛰기로 저하하지 않는다.
- #30 은 계속 조사 중이다: 일반 합성 작업에서 특정 system section 필터가 프로젝트 규약/기억을 제거함을 확인했지만 온라인 모델 품질 A/B 는 아직 완료하지 않았고, 이 버전이 능력 저하 피드백을 모두 해결했다고 주장하지 않는다.

[loLollipop](https://github.com/loLollipop) 의 수정, 감사, 테스트 기여에 감사한다. 자세한 내용은 [유지보수 안내](../maintenance-issues-27-30.md) 를 본다.

업데이트 설치 후 사용자가 편할 때 직접 종료하고 DSH 를 다시 연다. 설치는 현재 프로세스가 새 버전을 로드했다는 뜻이 아니다; 이번에도 사용자의 설치, 설정, 실행 프로세스를 자동으로 바꾸지 않았다.
