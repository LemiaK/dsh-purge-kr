# 1.6.40

- #53: `excludePresets` 를 추가하고, 기본값 `[]` 는 기존 동작을 유지한다. 현재 프리셋 ID 로 정확히 매칭하며 주 프롬프트, 머리/꼬리, 능력 설명, boost, probe, postPrompt, 호스트 폴백을 일관되게 제어한다.
- 제외된 세션은 기존 네이티브 페르소나와 워크스페이스 규칙을 유지한다; Purge 섹션을 정리하고, 출처가 기록된 자체 개정은 복원하며, 다른 플러그인이 이후 추가/수정한 내용은 보존한다. 사용자 프롬프트나 과거 대화를 삭제하지 않는다.
- 호스트 폴백은 현재 Agent 를 넘긴다; 옛 무인자 호출은 제외가 설정되어 있으면 주입을 멈춘다. 서브에이전트는 자기 실제 프리셋으로 판정하며 전역 "지난 세션" 상태를 두지 않는다.
- 전환, 병렬, 서브에이전트, 전체 프리셋, 옛 호스트 LF/CRLF 마이그레이션, 반복 적용 테스트와 실제 Cordis/SystemPrompt/요청 빌드 런타임 검수를 추가한다.

기존 설정, 권한 설정, 프록시는 바꾸지 않고, 패치를 자동 적용하거나 DSH 를 종료/재시작하지 않는다. 제외는 프롬프트만 제어하며 전역 호스트 패치를 철회하지 않는다. 옛 호스트 업데이트는 사용자가 적용 시점을 정하고 직접 종료 후 다시 열어야 한다.

설정과 테스트 경계는 [유지보수 안내](https://github.com/kingcharleslzy-ai/dsh-purge/blob/master/docs/maintenance-issue-53.md) 를 본다. REALOIYO 의 상세한 보고와 방안에 감사한다.
