# 1.6.33

PR #42 를 병합해 Linux CLI/Web 설치를 지원하고, 크로스 플랫폼 제거와 설치 실패 보호를 보강한다.

- **Linux 사용자 디렉터리 설치**: 시스템 npm 호스트가 쓰기 불가면 사용자 사본을 만든다. sudo 가 필요 없고, 시스템 디렉터리 권한이나 전역 npm 소스를 바꾸지 않는다.
- **성공 후 진입점 전환**: 마이그레이션이 실패하면 기존 `~/.local/bin/dsh` 를 유지한다; 최초 설치 실패 시 새 진입점을 활성화하지 않는다. 마이그레이션 중 진입점이 사용자에 의해 변경되었으면 중단하고 오류를 보고하며, 사용자 명령을 덮어쓰지 않는다.
- **제거 보호**: 플러그인 심볼릭 링크 또는 Windows junction 자체만 삭제하고, 외부 소스, 공유 패키지, 외부 profile 은 보존한다; 되돌리기나 등록 해제가 실패하면 정리를 계속하지 않는다.
- **경로 호환**: macOS `/var` 경로 별칭과 Linux 심볼릭 링크 home 을 일관되게 처리한다; Linux 디렉터리 경계는 대소문자를 구분한다.
- **기능과 설정 보존**: 호스트 패치 표, 프롬프트, 권한 선택, 업데이트 선호를 바꾸지 않았고, 패치를 자동 적용하거나 DSH 를 재시작하지 않는다.

검증에는 세 플랫폼 전체 테스트와 릴리스 패키지 smoke, Windows PowerShell 5.1/7 과 실제 Electron 인계, macOS 실제 Electron 진단이 포함된다. Ubuntu 비 root 환경의 공식 DSH 0.2.1-rc.2 npm 호스트 실측을 추가해 사용자 사본 설치, CLI 기동, 플러그인 임포트, 백업, 롤백, 실패 복구를 다룬다. Linux GUI 와 모델 작업은 전면 검수하지 않았으므로 모든 배포판과 완전히 호환된다고 주장하지 않는다.

[SimonQvQ](https://github.com/SimonQvQ) 의 Linux 지원과 CachyOS 검증에 감사한다. 자세한 경계는 [유지보수 기록](https://github.com/kingcharleslzy-ai/dsh-purge/blob/master/docs/maintenance-pr-42.md) 을 본다.
