# 1.6.41

자동 업데이트 영역이 계속 옛 버전의 "재시작 대기"를 표시하며 이후 자동 설치를 막는 문제를 수정한다.

- 현재 프로세스가 로드한 버전과 현재 profile 의 디스크 설치 버전을 대조해 상태를 판정한다; 버전 간 업그레이드와 롤백 모두 대체된 옛 기록을 인식한다.
- 디스크 패키지 교체를 실행 프로세스 로드로 오인하지 않는다: 재시작이 필요하면 두 버전을 함께 표시하고 자동 설치를 반복하지 않는다.
- 파일 누락, 패키지 신원 오류, 읽기 실패, 부분 설치 실패, 롤백 실패는 계속 표시한다; 업데이트 확인 성공이나 "새 버전 없음"이 설치 실패를 지우지 않는다.
- 자동 확인, 자동 설치, 간격, 프롬프트, 규칙 및 기타 기존 설정은 유지하고, 호스트 패치를 바꾸지 않으며 자동 적용/재시작도 없다.
- 버전 간 상태, 실패 복구, 패널, 실제 DSH 설치/롤백 테스트를 추가한다. 자세한 내용은 [유지보수 안내](../maintenance-update-state.md) 를 본다.

옛 프로세스가 잔여 상태에 걸려 있으면 유지보수 페이지에서 이 버전을 수동 설치한 뒤 직접 종료하고 한 번 다시 연다; 새 버전이 옛 기록을 자동으로 대조한다. 설정을 지우거나 업데이트 스위치를 바꿀 필요는 없다.
