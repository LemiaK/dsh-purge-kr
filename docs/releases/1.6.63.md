- 업스트림 1.1.83 에서 #188 의 범용 드리프트 판정을 가져왔다: 대상 파일이 있고 marker 가 없으며 앵커가 전부 맞지 않으면 → `drifted` 로 처리하고 더 이상 조용히 `skipped` 로 만들지 않는다; `patchStatusReady("drifted")` 는 false 이고, 패널은 "앵커 드리프트"로 표시하며, 자체 점검은 이상으로 집계한다.
- 예외: 자체 표식 패치(pattern 에 `[dsh-purge]` 포함)와 `silentWhenMissing`(#76)은 계속 `skipped` 이다; `fileOptional` 대상의 드리프트는 패치 전체에 영향을 주지 않는다.
- `ensureHostClean` 이 `pattern_not_found` 를 무시하지 않으며, 어정쩡한 상태를 안고 재시작을 계속하지 않는다.
