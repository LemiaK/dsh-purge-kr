# 1.6.54

## 옛 런타임 링크 마이그레이션과 오류 상세(#79 / #77)

- 평면 런타임에서 아키텍처 하위 디렉터리로 업그레이드할 때 같은 설치의 옛 runtime 링크를 식별하고 먼저 백업한 뒤 마이그레이션한다; 실제 디렉터리, 다른 대상을 가리키는 링크, 대상 파일은 보존한다.
- 마이그레이션 생성/검증이 실패하면 원래 링크를 복원한다; 복원이 실패하면 명시적으로 보고하고 백업을 보존하며, 권한, 파일 누락, 경로 충돌을 숨기지 않는다.
- 적용 실패 시 구체적 런타임 원인, 오류 코드, 런처 오류, 복구 상태를 표시한다; 백엔드 진단 상세를 더 이상 버리지 않고, 사용자 프롬프트나 전체 설정은 펼치지 않는다.
- 기본 테스트 명령에서 빠진 데스크톱 대상 식별 테스트를 복원하고, 마이그레이션, 실패 복구, 실제 HTTP 오류 해석 회귀를 보강한다.

테스트 증거와 경계는 저장소의 [유지보수 기록](../maintenance-issue-79.md) 을 본다. 자동 재시작은 없고 사용자 설정을 바꾸지 않는다. 이 수정은 이미 재현된 런타임 레이아웃 문제를 다룬다; 보고자의 구체적 환경과 재시작 후 프리셋이 사라지는 문제는 아직 확인이 필요하다.
