# 1.6.47

#68 을 수정한다: electron-vite 데스크톱 레이아웃의 진입점 탐색 누락 때문에 #82/#83/#84 가 누락으로 잘못 보고되었다.

- 선택한 설치의 `resources/app/package.json` 에 있는 `main` 을 우선 읽고, 옛 `main.js`, `lib/main.js`, `out/main/index.js`, `out/main/main.js` 를 함께 지원한다. 자체 점검, 진단, 적용이 하나의 파서를 공유한다.
- 명시적으로 선언되었으나 없거나 읽을 수 없는 진입점은 조용히 폴백하지 않는다; 경계를 벗어난 경로, 외부를 가리키는 링크, 선언이 없고 진입점이 여러 개인 경우는 오류로 유지한다. 다른 설치를 검색하거나 실제 누락을 초록으로 표시하지 않는다.
- 진단은 `desktop_entry` 의 해석 상태와 출처를 제공한다. 기존 패치 내용, 선택성, 오류 등급은 유지한다.
- 신구 레이아웃, 선언 우선, 잔여 진입점, 비정상 manifest, 경로 경계, 인스턴스 간 격리, 실제 Electron 에서의 적용/반복 적용/자체 점검/진단 테스트를 보강한다; ASAR 과 물리 디렉터리가 공존할 때 올바른 대상을 읽는지 검증한다.

기존 기능, 프롬프트, 설정은 유지하고 DSH 를 자동 재시작하지 않는다. 1.6.46 의 Junction 정리 수정을 포함한다; 1.6.45 이전 Windows 사용자는 새 버전 독립 설치기로 업그레이드해 옛 프로세스가 옛 정리 코드를 실행하지 않게 한다. 재현을 제공한 @zebulonpeng 에게 감사한다.
