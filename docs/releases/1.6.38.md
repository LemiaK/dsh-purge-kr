# Purge Community 1.6.38

- #44 / PR #47: 정식 릴리스 패키지 다운로드 예산을 따로 설정하며 기본 180초다; 기본 비활성인 URL 접두사 미러를 추가한다. 미러는 TGZ 만 전송하고 SHA256 은 공식 경로에서 오며 토큰은 미러로 보내지 않는다. 다운로드나 검증 실패가 더 이상 설치 롤백을 유발하지 않는다.
- PR #45: 항목 생성 전의 중복 설정 수정을 제거하고 전체 플러그인 정의, 사용자 오버라이드, 옛 패키지 마이그레이션 동작을 유지한다.
- PR #46: 감사 디렉터리, 기존 로그, 로테이션 후 새 파일의 소유자 처리를 보완하고 사설 권한을 유지하며 심볼릭 링크와 하드 링크를 거부하고 읽기 권한 이상을 빈 로그로 표시하지 않는다.
- 실기 설치 검수에서 Windows 짧은 경로/디렉터리 별칭 때문에 롤백 패키지의 pnpm 캐시 파일 이름이 너무 길어지는 문제를 발견해 수정했다; 패키지 관리자에 넘기기 전에 실제 경로를 해석하고 원본 아카이브, 설정, 실패 복구를 보존한다.
- 실제 Linux root/서비스 사용자 권한 테스트, 실제 DSH 설정 합성, 세 플랫폼의 공식 npm 호스트 설치·업그레이드·롤백·실패 복구 검수를 추가했다. 기존 Electron 및 기능 회귀 기준은 유지한다.

기존 프롬프트, 프리셋, 프록시, 업데이트 선호를 바꾸지 않고 호스트 패치를 자동 적용하지 않으며 DSH 를 자동 종료하거나 재시작하지 않는다. 재현과 세 개의 PR 을 제공한 alexopenfan-xiaxin 에 감사한다; 통합판은 제안의 검증 출처와 파일 소유권 경계를 보완했다.

설정 방법, 적용 범위, 롤백 주의 사항은 [유지보수 안내](../maintenance-issues-44-47.md) 를 본다.
