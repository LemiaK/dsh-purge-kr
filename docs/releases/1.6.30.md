# 1.6.30

## 수정

- PR #33 병합: npm 단일 패키지 중첩 호스트 레이아웃을 지원한다. 설치 루트와 컴포넌트 루트를 분리해 해석하고, 자체 점검은 올바른 컴포넌트를 읽으며 실제 설치, 업그레이드, 롤백 진입점은 유지한다.
- 자체 점검 집계를 수정한다: 명확히 해당 없음, 비활성, 실행할 필요가 없는 마이그레이션만 제외한다; 필수 파일 누락은 분모에 유지하고 경고하며, 적용 대기와 미지 상태를 더 이상 성공으로 오보하지 않는다.
- 자체 점검은 지정한 인스턴스의 고정 레이아웃만 검사하고 다른 Desktop 이나 전역 설치를 폴백으로 스캔하지 않는다. 대상 정보가 없으면 명확히 알린다.
- 기존 호스트 패치, 프롬프트, 권한, 프리셋, 업데이트 선호는 그대로이며 패치를 자동 적용하거나 DSH 를 재시작하지 않는다.

## 검증

- PR 의 전체 GitHub 검사가 통과했다: Linux, macOS, Windows 설치 테스트, Windows PowerShell 5.1/7, 실제 Electron 인계, 문서·패널·설치 패키지 검사.
- 자동 테스트 205건: macOS 200 통과, 5건 플랫폼 건너뜀; Windows 201 통과, 4건 플랫폼 건너뜀.
- Windows 11 실기 격리 환경에서 실제 DSH 0.2.1-rc.2 CLI 와 npm 전역 모드 중첩 레이아웃을 사용했다: 옛 버전 설치, 후보 업그레이드, 스냅샷 롤백, 재업그레이드, 주입 검증 실패 후 복구가 모두 통과했고 단계마다 새 프로세스가 플러그인 진입점을 로드했다. 기존 설정과 프록시 다이제스트는 변하지 않았고 사용자 DSH 를 재시작하지 않았다.
- 실기 후보 패키지 식별자는 1.6.30-pr33.1 이다; 정식 패키지는 버전과 문서만 동기화하고 계속 릴리스 파이프라인에서 다시 테스트하고 패키징한다. 이 기록은 새로운 GUI 또는 모델 품질 검수와 같지 않다.

[youki258](https://github.com/youki258) 님이 수정과 테스트를 제출했으며 기여자 목록에 추가했다. 자세한 내용은 [유지보수 안내](../maintenance-pr-33.md) 를 본다.
