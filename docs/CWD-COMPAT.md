# cwd 템플릿 호환 수정

이 수정은 Purge Community `1.2.0` 에 포함되었다. 최초 로컬 호환 패키지는 `1.1.71-compat.cwd.1` 이다. 이 버전은 프롬프트 렌더링의 누락 변수 오류만 고치며 호스트 패치를 확장하거나 다시 적용하지 않는다.

업스트림 issue #114 와 PR #115 에 연결된 사안이다(원 업스트림 저장소는 더 이상 접근할 수 없어 번호는 기록용으로만 남긴다). 이 PC 의 DSH 0.2.1-rc.1 도 provider/model 만 등록하므로 `Your working directory is {{cwd}}.` 를 주입하면 요청을 보내기 전에 오류가 난다.

- 설정 템플릿의 personaSuffix 를 비워 설정 계층이 없는 변수를 요구하지 않게 한다.
- 런타임은 assembled.variables 의 cwd 가 존재하고 undefined 가 아닌지에 따라 동적 접미사나 정적 폴백을 고른다.
- 사용자 프롬프트 파일을 바꾸지 않고 기본이 아닌 사용자 지정 접미사를 덮어쓰지 않으며 호스트 assembly 를 제자리에서 바꾸지 않는다. 반복 처리는 멱등이다.
- 모델 인터페이스, 신원/규칙 처리의 다른 로직, 기존 설정, 독립 인터페이스 플러그인을 바꾸지 않는다.

대상 DSH 의 실제 system-prompt 모듈로 회귀 테스트를 실행한다:

```sh
node test/cwd-compat.mjs /absolute/path/to/dsh-system-prompt/lib/index.js
```

테스트는 누락, undefined, 유효 경로, 빈 문자열을 포함하며, 각각에 접미사 없음, 옛 cwd 접미사, 사용자 지정 접미사를 다시 시험해 모두 12 개 시나리오를 돈다. 렌더링 테스트 통과가 모든 Purge 패치의 새 DSH 호환성을 검증했다는 뜻은 아니다. 네이티브 대화 검수는 플러그인을 다시 로드한 뒤 별도로 확인한다.
